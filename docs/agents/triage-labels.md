# Метки triage

Скилы оперируют пятью каноническими ролями triage. Этот файл сопоставляет роли с реальными строками меток в трекере задач этого репозитория.

| Метка в mattpocock/skills | Метка в нашем трекере | Значение                                   |
| -------------------------- | --------------------- | ------------------------------------------- |
| `needs-triage`             | `needs-triage`        | мейнтейнеру нужно оценить эту задачу       |
| `needs-info`               | `needs-info`          | ждём от автора дополнительной информации    |
| `ready-for-agent`          | `ready-for-agent`     | полностью описано, готово для автономного агента |
| `ready-for-human`          | `ready-for-human`     | требует реализации человеком                |
| `wontfix`                  | `wontfix`             | делать не будем                            |

Когда скил упоминает роль (например, «поставить метку AFK-ready»), используйте соответствующую строку метки из этой таблицы.

Правьте правую колонку под фактический словарь меток вашего трекера.
