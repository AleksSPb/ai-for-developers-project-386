# Брони хранятся в браузере, за портом

Брони живут в `localStorage` браузера, а код обращается к ним только через порт
хранилища с одной реализацией.

Сервера нет, и это осознанное ограничение: две вкладки в разных браузерах не
видят друг друга, поэтому один и тот же Слот может оказаться забронирован
дважды, а очистка данных браузера освобождает все Слоты заново. Ограничение
объявлено в README, а не оставлено на discovery.

Порт оставлен именно для того, чтобы сервер был заменой одной реализации, а не
переделкой домена: пока он есть, решение остаётся обратимым.
