# Длительность Типа события задаётся один раз

Длительность задаётся при создании Типа события и больше не меняется: у Владельца
нет ни правки, ни удаления, ни предупреждения о том, что существующие Брони ей
перестанут соответствовать.

Проверка «длительность интервала равна длительности Типа», которую делает сервер
при записи, сделала бы последствие необратимым: Брони, созданные по старой
длительности, перестали бы ей соответствовать и потребовали бы миграции. Запрет
на правку снимает эту проблему целиком, а не сдвигает её.

Цена — в форме Владельца поле длительности нельзя изменить, и это выглядит как
недоделка. Альтернатива была — разрешить правку и решить, что делать с
несоответствующими Бронями: оставить как есть (тогда сверка на сервере придётся
ослабить), либо переписывать их (тогда это миграция данных, а не изменение
настройки).
